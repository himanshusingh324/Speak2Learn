# Speak2Learn

Speak2Learn is a voice-to-concept technical-interview coach. A student answers a placement interview question aloud, the app displays the transcript, and the evaluation module compares it with an interviewer-defined rubric.

## Run it

This free version uses browser speech recognition. No OpenAI API key, billing account, or transcription server is required.

Open `index.html` in the latest Google Chrome or Microsoft Edge. Allow microphone access, choose a question, and press **Start recording**. Your transcript appears while you speak; press the button again to stop.

Speech recognition support and its network requirements depend on the browser. You can always type directly in the transcript box.

## Included features

- Placement-oriented questions for DBMS, Operating Systems, and DSA
- Record/type an answer and review its transcript
- Rubric evaluation with covered concepts, gaps, misconception flags, and readiness score
- Sample answers for repeatable end-to-end demonstration
